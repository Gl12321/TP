# Общие механизмы приложения

Эта директория содержит технические механизмы, которым не нужны понятия выручки, плана или управляющего точки. Она помогает предметным модулям согласованно работать с БД, секретами и HTTP, не создавая универсальную надстройку над каждой операцией.

[database.py](database.py) создаёт асинхронный SQLAlchemy engine и транзакцию запроса. Успешное изменение с участником записывается в журнал аудита; ошибка откатывает транзакцию. SQLite включает внешние ключи и WAL для локальных интеграционных проверок. Рабочая конфигурация использует PostgreSQL.

[security.py](security.py) хеширует пароли scrypt, создаёт хеши сессионных токенов и шифрует секреты источников. Ключ источников выводится из `APP_SECRET_KEY`; его потеря делает сохранённые подключения нечитаемыми, поэтому резервная копия БД требует отдельного защищённого сохранения ключа. Ограничение вычислений паролей предотвращает неограниченное число параллельных затрат памяти.

[config.py](config.py) читает несекретные настройки YAML и явные переменные окружения. [http.py](http.py) ограничивает реальное тело запроса двумя МиБ, включая chunked-передачу, до разбора JSON. [errors.py](errors.py) задаёт публичную форму ошибки без содержимого паролей или строки подключения.

Сборка этих механизмов находится в [main.py](../main.py), миграции — в [migrations](../../migrations/README.md). API не создаёт таблицы автоматически при запуске и не загружает локальную LLM.
