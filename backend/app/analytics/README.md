# Показатели, планы и отчёты

Руководителю нужна воспроизводимая цифра: по каким точкам, за какой период и по какому определению она посчитана. Модуль связывает внешние коды точек с источником, хранит определения показателей и редакции планов, рассчитывает обзор обычным кодом.

[models.py](models.py) хранит версии определений и планов. Определение указывает таблицу, ключ точки, поле даты, поле значения и агрегат. Изменение создаёт новую редакцию и не переписывает прежний расчёт. Значения денег передаются как decimal-строки; план без значения отличается от нулевого.

[service.py](service.py) строит проверяемый SELECT для обзора и выполняет его через тот же ограниченный [источник](../sources/README.md), что используется ассистентом. Конец выбранного периода включителен: в SQL применяется граница следующего дня. Полный календарный месяц сравнивается с предыдущим календарным месяцем: октябрь — с сентябрём, март — со всем февралём с учётом високосного года. Несколько полных месяцев сравниваются с предыдущим блоком такого же числа месяцев. Произвольный диапазон сравнивается с непосредственно предшествующим диапазоном той же длительности в днях. Сопоставимое изменение использует точки со значением в обоих периодах; средние считаются с весами, а не средним от средних.

Планы суммируются только за полные календарные месяцы. Выполнение плана учитывает одинаковую область факта и плана. Средние планы разных месяцев не складываются без весов. Отсутствие строк отмечается как отсутствие данных; оно не превращается в ноль или доказанное падение бизнеса. Полноту выгрузки текущая версия автоматически не подтверждает.

Сохранённый отчёт ссылается на конкретный снимок результата и его SQL. Повтор отчёта создаёт новое [задание](../jobs/README.md) и проверяет запрос по текущему каталогу без новой генерации. Предыдущий снимок сохраняется. Совместное чтение отчёта требует доступа ко всей области результата; личная переписка автора не становится общей.
