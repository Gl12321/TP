# Личный вопрос к данным

Пользователь задаёт вопрос обычными словами и получает таблицу вместе с исполнившимся SQL. Продолжение «а теперь по городам» связывается с явно выбранным прежним расчётом. При необходимости уточнения сохраняется отдельное состояние, а не выдуманная таблица.

[service.py](service.py) атомарно создаёт сообщение, запуск и долговечное задание. Ключ идемпотентности защищает повторную отправку; версия диалога предотвращает незаметную перезапись из другой вкладки. Одновременно в диалоге выполняется один запрос. Личный диалог принадлежит пользователю, а сохранение результата в отчёт является отдельным действием.

[engine.py](engine.py) соединяет приложение с [sql_agent](../../../packages/sql_agent/README.md). История ограничена выбранным основанием: вопросом, SQL и условиями. Строки результата и комментарии коллег в модель не передаются. Определения показателей включают конкретные поля и агрегаты, чтобы ассистент видел тот же смысл, что обычный обзор.

Результат различает SQL расчёта и фактически исполненный запрос. Первый нужен для чтения и продолжения вопроса; второй включает серверные ограничения полей и строк и отдельно сохранённые параметры. Эта информация доступна с той же проверкой области, что и сама таблица, и не содержит пароля источника.

`run.context` хранит выбранные условия, версии и область; это не доказательство того, какой период модель использовала в SQL. Проверять вычисление можно по сохранённому запросу и результату. Противоречие между явно выбранным периодом и новым вопросом требует уточнения. При продолжении отсутствующие условия наследуются от основания; явно переданные поля относятся к новому запросу.

[routes.py](routes.py) выдаёт историю и события SSE. Пропуск события исправляется повторным GET запуска; закрытие подписки не отменяет работу. Отдельная команда отмены переводит активный запрос в ожидание остановки. Доступ проверяется при каждом чтении результата и повторно во время потока. При отзыве области скрываются также относящиеся к ней сообщения и заголовок диалога.
