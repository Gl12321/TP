# Разборы и разговор по фактам

Разбор объединяет факт и человеческое объяснение. Руководитель может прикрепить результат по точке, задать вопрос управляющему и записать принятое действие. Ответ сотрудника остаётся сообщением человека: он не меняет числа и не вызывает языковую модель.

[routes.py](routes.py) создаёт карточку, комментарии и адресные вопросы. Ответить на адресный вопрос может его получатель. Закрыть разбор с обязательным итогом может автор, ответственный или руководитель. После закрытия история доступна для чтения и не дополняется незаметно новыми сообщениями.

[service.py](service.py) проверяет область и адресата. Узкая карточка не может содержать более широкий сетевой результат. Прикрепление таблицы разрешается только при доступе ко всему результату; скрытие нескольких строк на фронтенде не используется. Уведомление ведёт к разбору и повторно проверяет доступ перед показом заголовка и текста.

Карточка связана с [аналитическим результатом](../analytics/README.md), но не раскрывает личный [диалог](../assistant/README.md). Встроенные уведомления хранятся в БД приложения. Отправка почты, мессенджеров и автоматическое составление причинного объяснения в этот модуль не входят.
