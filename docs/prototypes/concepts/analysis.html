Условия этого шага

Как считаем

Поступления минус возвраты. Оплаты учитываем по дате поступления денег, возвраты — по дате возврата. Это движение денег, не бухгалтерская выручка.

Возврат в июне по майскому заказу уменьшает июньскую сумму. Город берём из исходного заказа.

SQL выбранного шага

Эскиз запроса над подготовленной таблицей денежных операций. Поступления положительные, возвраты отрицательные; дата — дата самой операции. SQL в макете не исполняется.
