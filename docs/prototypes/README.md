# Концепт рабочего пространства

[Открыть HTML-концепт](workspace.html) — отдельный кликабельный пример будущего интерфейса. Его можно открыть прямо в браузере; сервер, установка библиотек и доступ к сети не нужны.

Концепт показывает, как вопрос превращается в проверяемый анализ: определение показателя, видимые условия, таблица, график и SQL относятся к одному результату. Это материал для обсуждения устройства продукта. Рабочий интерфейс приложения остаётся в [frontend](../../frontend/README.md); возможности концепта не означают их реализацию в приложении.

## Что попробовать

1. Переключить «Оплаченные заказы» на «Все созданные заказы». Суммы и количество заказов изменятся; в SQL исчезнет фильтр `status = 'paid'`.
2. Выбрать Москву и другой период. Таблица, итог, график, подписи и SQL используют одинаковые условия.
3. Открыть вкладку «График». Она показывает те же значения, что таблица; смена вкладки не создаёт новый анализ.
4. Сохранить анализ, изменить условия и открыть сохранённый вариант. Исходные условия восстановятся. К предыдущим вариантам можно вернуться также из истории слева.
5. Открыть «Данные», чтобы посмотреть предполагаемое место каталога источников и определений полей.

Все данные вымышлены. Локальный пример содержит агрегированные суммы и количество оплаченных и неоплаченных заказов по двум регионам и шести месяцам. JavaScript объединяет эти значения по выбранным условиям. SQL демонстрирует соответствующий запрос к предполагаемой таблице заказов, но не выполняется.

История и сохранённые анализы находятся только в памяти страницы. Перезагрузка вкладки их удаляет. Прототип не использует localStorage, не создаёт файлы, не подключается к БД и не вызывает модель. Свободный ввод вопросов, импорт данных и редактирование SQL в нём отсутствуют.

## Связь с проектом

Концепт развивает текущую идею [интерфейса](../../frontend/README.md): результат остаётся основным содержимым, а сведения о расчёте можно изучить отдельно. Типы колонок, история и определения показателей здесь заданы демонстрационными правилами; для рабочего приложения потребуются соответствующие изменения [API](../../src/api/README.md) и [общих типов результата](../../src/domain/README.md).

HTML содержит стили, SVG-график и логику взаимодействий в одном файле, без внешних зависимостей. Это не выбор фреймворка и не начало миграции фронтенда.
