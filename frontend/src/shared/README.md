# Общий язык интерфейса

Пользователь должен одинаково понимать пустой результат, ограниченную выдачу, ошибку и успешное действие на любой странице. Этот слой задаёт единые формы, состояния, представление таблиц и правила обращения к серверу.

[api/client.ts](api/client.ts) добавляет cookie и CSRF, нормализует ошибки и сообщает об истечении сеанса. [api/contracts.ts](api/contracts.ts) описывает данные backend. У запросов нет встроенных демонстрационных ответов. [api/queries.ts](api/queries.ts) задаёт общие ключи кэша с пространством в каждом ключе.

[results/ResultPanel.tsx](results/ResultPanel.tsx) показывает результат вместе с датой расчёта, условиями и SQL. Внутри раскрываемого блока есть фактически исполненный запрос и параметры после ограничения области точек. [DataTable](results/DataTable.tsx) сортирует и разбивает только уже полученные строки; это не дополнительные запросы к источнику. [export.ts](results/export.ts) сохраняет точные исходные значения и экранирует формулы CSV. [ui/format.ts](ui/format.ts) округляет денежные строки без потери больших целых и различает отсутствие значения и ноль.

[ResultChart](results/ResultChart.tsx) строит столбцы или линию для выбранной подписи и числового столбца. График использует строки результата без агрегации и перестановки; пропуски не заменяются нулями, повторяющиеся подписи не объединяются. Для длинной выдачи пользователь явно выбирает первые 20, 50 или 100 строк. Ограничение исходной выдачи сохраняется в подписи графика. Точные десятичные значения остаются в таблице и подсказках; координаты SVG вычисляются с точностью браузерного Number.

[styles/global.css](styles/global.css) задаёт палитру и базовые правила. `components.css` оформляет повторяемые элементы, `layout.css` — каркас и вход, `features.css` — сценарии. Светлая основа, тёмная навигация и насыщенный синий используются последовательно; шрифты не загружаются из внешних сервисов.

Этот слой используется [страницами](../features/README.md) и [каркасом](../app/README.md). Он не хранит определения бизнес-показателей и не принимает решения о доступе вместо API.
