# Код пользовательского приложения

Интерфейс ведёт пользователя от данных сети к вопросу, таблице и предметному обсуждению. Здесь нет отдельной модели или локальной копии базы: страницы обращаются к Python backend и показывают сохранённые сервером факты.

[app](app/README.md) связывает сессию, пространство и навигацию. [features](features/README.md) реализует пользовательские сценарии. [shared](shared/README.md) задаёт общие формы, транспорт и представление результатов. [main.tsx](main.tsx) подключает маршрутизацию, серверный кэш и стили.

Сборка, запуск и проверки описаны в [frontend/README.md](../README.md). Контракт границы с Python находится в [backend/API.md](../../backend/API.md).
