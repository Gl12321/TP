# Оболочка рабочего пространства

Переход между обзором, вопросами и обсуждениями должен сохранять ощущение одного приложения. Оболочка даёт человеку постоянную навигацию, переключение сети, профиль и входящие уведомления. Она показывает только доступные разделы и переносит выбранные период, показатель и область точек между страницами.

[AppShell.tsx](../AppShell.tsx) собирает общую раскладку и очищает кэш предыдущего пространства при переключении. Разделы и необходимые полномочия перечислены в [model/navigation.ts](model/navigation.ts). [NotificationDialog](components/NotificationDialog.tsx) открывает конкретный разбор или обращение и отмечает уведомление прочитанным после подтверждения сервера. [useMobileNavigation](hooks/useMobileNavigation.ts) управляет выдвижной панелью, фокусом и прокруткой.

Узкий экран использует ту же навигацию в модальной панели. Tab остаётся внутри открытой панели, Escape закрывает её, скрытые элементы исключаются из взаимодействия. Смена ширины окна восстанавливает доступность основного содержимого и переводит фокус на видимый элемент. Переход к странице направляет фокус к её содержимому.

Права приходят из [сессии](../session.tsx) и [пространства](../workspace.tsx); сервер остаётся источником решений о доступе. Оболочка не загружает финансовые результаты и не запускает агент. Страницы предметных сценариев находятся в [features](../../features/README.md).
