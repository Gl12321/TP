# Первые шаги пространства

Первый вход должен объяснять, как получить первый полезный расчёт. Пустой график не помогает понять, чего ещё не хватает. Этот экран показывает три конкретных шага: точки, разрешённый источник данных и согласованный показатель. Каждый шаг объясняет его смысл, учитывает уже сделанную настройку и ведёт прямо в нужную вкладку.

[WorkspaceSetup.tsx](components/WorkspaceSetup.tsx) использует существующие запросы справочников через TanStack Query. Отдельного серверного состояния мастера нет: прогресс отражает реальные данные и остаётся правильным, когда другой участник заканчивает настройку. Источник считается подготовленным после успешной проверки соединения и выбора разрешённых таблиц. Роль определяет доступные действия; сотруднику без нужных прав объясняется, кто выполняет этот шаг. Компоненты находятся в `components`, оформление — в [styles/setup.css](styles/setup.css).

Экран связан с [настройками](../settings/README.md), [источниками и определениями](../data/README.md) и [обзором](../overview/README.md). До появления первого показателя обзор показывает настройку без пустых фильтров расчёта. Планы и приглашения не блокируют первый расчёт. Компонент не создаёт демонстрационные показатели и не выдаёт отсутствие данных за нулевой результат.
