# Список разборов

[CasesPage](CasesPage.tsx) показывает доступные обсуждения и представления «Мои» и «Ждут моего ответа». Идентификатор в маршруте переключает список на карточку выбранного разбора.

Страница подключается в [App](../../../app/App.tsx). Обсуждение отображает [CaseView](../components/CaseView.tsx), создание выполняет [CaseCreateDialog](../components/CaseCreateDialog.tsx), а подписи состояний задаёт [модель](../model/status.ts).

Параметры `q` и `filter` из URL передаются серверу; ключ `useInfiniteQuery` включает оба значения. [getPage](../../../shared/api/client.ts) получает записи и курсор, а [Pagination](../../../shared/ui/Pagination.tsx) показывает число загруженных разборов и кнопку продолжения. Пустой `items` при наличии курсора не завершает список. Ошибка дозагрузки выводится внизу, ошибка обновления — над списком; полученные строки сохраняются в обоих случаях.
