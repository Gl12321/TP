# Обсуждение с проверяемым основанием

Разбор связывает конкретную точку и наблюдение с вопросом ответственному сотруднику. Участники добавляют проверенные обстоятельства, отвечают на адресные вопросы, а автор фиксирует итог. Прикреплённая таблица остаётся отдельным неизменяемым основанием.

[CaseCreateDialog.tsx](CaseCreateDialog.tsx) задаёт область и предмет. [CasesPage.tsx](CasesPage.tsx) показывает комментарии, адресные вопросы, ответы и итог. Список получателей приходит от API для всей области разбора; после изменения команды он загружается заново. Новое сообщение не меняет данные источника.

[Measurements.tsx](Measurements.tsx) показывает серверные снимки штатного показателя и позволяет автору повторить измерение за другой период, включая проверку после зафиксированного итога. Прежнее наблюдение и вывод сохраняются; новый результат не возобновляет обсуждение автоматически. Разница относится к сопоставимому составу точек, а не объявляется доказанным эффектом решения.

Представления «Мои» и «Ждут моего ответа» разделяют собственные разборы и адресные вопросы. Черновики комментария, вопроса и итога сохраняются раздельно в памяти текущего сеанса при переходах между страницами; выход очищает их. Перезагрузка браузера не является сохранением черновика на сервере.

Разбор можно создать из [точки](../stores/README.md) либо результата [ассистента](../assistant/README.md). Личная история вопросов не передаётся коллегам. Уведомления отображает общий [AppShell](../../app/AppShell.tsx), а разрешение на чтение основания и участие независимо проверяет backend.
