# Подписи состояний разбора

[status.ts](status.ts) переводит серверное состояние в понятную подпись: открытый разбор, ожидание ответа, полученный ответ или зафиксированный итог. Неизвестное значение сохраняется как есть.

Используйте `caseStatus` в [списке разборов](../pages/CasesPage.tsx), [карточке](../components/CaseView.tsx) и [странице точки](../../stores/pages/StoresPage.tsx). Функция не меняет состояние и не задаёт правила переходов.
