# Предметное обсуждение

[CaseCreateDialog](CaseCreateDialog.tsx) сохраняет тему, область и исходное наблюдение. [CaseView](CaseView.tsx) ведёт комментарии, адресные вопросы, ответы и итог; отдельные черновики сохраняют незавершённый ввод при переходах.

[Measurements](Measurements.tsx) показывает серверные снимки показателя и позволяет повторить измерение. Прежнее основание и итог остаются в истории, а новое измерение само по себе не возобновляет обсуждение.

Карточка получает идентификатор разбора от [страницы](../pages/CasesPage.tsx). Форму `CaseCreateDialog` используют также [точки](../../stores/pages/StoresPage.tsx), передавая выбранный показатель и область. [ResultPanel](../../../shared/results/ResultPanel.tsx) создаёт разбор собственной формой сохранения готового SQL-результата: её основание — конкретный `run_id`. Список получателей и доступ к нему проверяются сервером.
