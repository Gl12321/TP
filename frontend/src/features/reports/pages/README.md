# Возврат к сохранённому результату

[ReportsPage](ReportsPage.tsx) показывает список отчётов и историю выбранного расчёта. Пользователь открывает прежний результат, сравнивает сохранённые попытки или повторяет SQL отдельным заданием.

Страница подключается в [App](../../../app/App.tsx) и использует [RunCard](../../assistant/components/RunCard.tsx) для состояния запуска и готового ответа. Выбранная попытка хранится в URL; неудачный пересчёт не заменяет успешную таблицу.

Список использует `useInfiniteQuery` с серверным поиском по `q` и курсором следующей страницы. Параметры поиска сохраняются при переходах к карточке и обратно; счётчик относится к уже полученным отчётам. Ошибка следующей страницы показывается отдельно и не скрывает загруженные карточки.
