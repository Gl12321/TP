# Сохранённые расчёты

Отчёт даёт команде постоянную точку возврата к полезной таблице. Открытие отчёта показывает сохранённый результат с его временем и SQL, а не незаметно изменившиеся числа.

[ReportsPage.tsx](ReportsPage.tsx) показывает список и выбранный отчёт. «Пересчитать SQL» создаёт отдельное задание без новой генерации. История хранится на сервере: исходный и повторные расчёты доступны после перезагрузки страницы, выбранный запуск указан в URL. Неудачная попытка не заменяет успешный результат. Экспорт, график и раскрытие SQL предоставлены общим [ResultPanel](../../shared/results/ResultPanel.tsx).

Отчёт создаётся из результата [ассистента](../assistant/README.md). Backend проверяет актуальное право на сохранённую область; наличие ссылки на отчёт не предоставляет доступ к другим точкам.
