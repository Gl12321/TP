# Сохранённые расчёты

Отчёт даёт команде постоянную точку возврата к полезной таблице. Открытие отчёта показывает сохранённый результат с его временем и SQL, а не незаметно изменившиеся числа.

[Страница отчётов](pages/ReportsPage.tsx) показывает список и выбранный отчёт. «Пересчитать SQL» создаёт отдельное задание без новой генерации. История хранится на сервере: исходный и повторные расчёты доступны после перезагрузки страницы, выбранный запуск указан в URL. Неудачная попытка не заменяет успешный результат. Экспорт, график и раскрытие SQL предоставлены общим [ResultPanel](../../shared/results/ResultPanel.tsx).

Список загружается страницами по 50 записей, а поиск по `q` выполняется на сервере. Открытие отчёта, выбор попытки и возврат к списку сохраняют поисковый запрос в URL. Счётчик показывает загруженное количество; «Показать ещё» получает следующую страницу. Ошибка дозагрузки оставляет текущие карточки на экране и даёт повторить запрос.

Отчёт создаётся из результата [ассистента](../assistant/README.md). Backend проверяет актуальное право на сохранённую область; наличие ссылки на отчёт не предоставляет доступ к другим точкам.
