# Вопрос превращается в таблицу

Ассистент нужен, когда готового показателя недостаточно: пользователь описывает нужный срез данных обычными словами и получает таблицу вместе с SQL. Каждый запуск сохраняет источник, область, период, результат и статус. Диалог личный; передача отдельной таблицы в отчёт или разбор выполняется явно.

[AssistantPage.tsx](AssistantPage.tsx) разделяет условия следующего вопроса и уже готовые расчёты. Период необязателен: при пустом поле он определяется вопросом или уточняется агентом. Переход из обзора сохраняет явно выбранный месяц. Продолжение связывается с конкретным запуском через `base_run_id`. Ключ повторной отправки зависит от содержания вопроса, а не от технической версии диалога, чтобы потерянный сетевой ответ не создавал дубликат.

[useRun.ts](useRun.ts) получает события сервера и периодически сверяет фактическое состояние. Закрытие вкладки прекращает наблюдение; отмена отправляется отдельно. [RunCard.tsx](RunCard.tsx) показывает очередь, работу, уточнение, отказ или [готовый результат](../../shared/results/ResultPanel.tsx). После ошибки проверки доступа старый результат скрывается.

Модель работает в backend worker через отдельный `sql_agent`. Браузер передаёт вопрос и условия; он не формирует SQL, не ограничивает область строк вместо сервера и не отправляет комментарии коллег модели.
