# Вопросы к данным

[AssistantPage](AssistantPage.tsx) связывает личную историю с условиями следующего вопроса. Пользователь выбирает доступный источник, область и период, затем получает сохранённый запуск или отвечает на уточнение.

Страница подключается маршрутом ассистента в [App](../../../app/App.tsx). Карточки результатов берутся из [components](../components/README.md), а наблюдение за вычислениями находится в [hooks](../hooks/README.md). При смене условий готовые результаты сохраняют свой исходный контекст.

Для истории используется `useInfiniteQuery`: `q` задаёт серверный поиск, а курсор из ответа загружает следующую страницу. Ключ кэша включает поисковый запрос; уже полученные страницы сохраняются при ошибке следующей. Счётчик показывает загруженное количество, а не общее число разговоров.
