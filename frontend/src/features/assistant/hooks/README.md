# Наблюдение за вычислением

[useRun](useRun.ts) поддерживает актуальное состояние серверного запуска, пока пользователь смотрит его результат. Поток событий ускоряет обновления, а периодический запрос сохраняет работоспособность при потере соединения.

Хук принимает пространство, идентификатор запуска и необязательный исходный `Run`. Он возвращает состояние запроса и соединения для [RunCard](../components/RunCard.tsx). Завершение вычисления останавливает наблюдение; закрытие страницы освобождает соединение и не отменяет серверное задание.
