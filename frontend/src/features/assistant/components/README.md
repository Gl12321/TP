# Состояние расчёта

[RunCard](RunCard.tsx) показывает, что происходит с отдельным запросом: ожидание, выполнение, уточнение, ошибку или готовую таблицу. Из карточки можно остановить активный запуск или продолжить выбранный результат.

Компонент получает исходный `Run`, необязательный `reportId` и обработчик продолжения. Данные обновляет [useRun](../hooks/useRun.ts); готовый ответ отображается общим [ResultPanel](../../../shared/results/ResultPanel.tsx). Карточку используют и [ассистент](../pages/AssistantPage.tsx), и [отчёты](../../reports/pages/ReportsPage.tsx).
