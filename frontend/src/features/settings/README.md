# Команда и область ответственности

Роль определяет доступные действия, а набор точек — доступные данные. Настройки позволяют пригласить сотрудника с нужными полномочиями, изменить его область и отключить доступ, сохранив историю работы.

[Страница настроек](pages/SettingsPage.tsx) содержит профиль, команду и справочник точек. Владелец пространства защищён от обычного ограничения доступа. [Приглашения](components/InvitationsPanel.tsx) выдают одноразовую ссылку; сотрудник задаёт пароль при принятии либо входит существующим аккаунтом. Ссылка показывается только при создании, хранить её в клиентском хранилище не требуется.

Вкладки открываются по адресу `settings?tab=profile`, `settings?tab=members` и `settings?tab=stores`, поэтому обновление страницы и история браузера сохраняют выбранный раздел. Команда и справочник доступны только с правом управления участниками; ссылка на недоступную вкладку открывает собственный профиль.

[Настройки безопасности](components/SecurityPanel.tsx) меняют пароль и завершают остальные сеансы. [Создание пространства](components/CreateWorkspace.tsx) добавляет отдельную сеть с независимыми данными и участниками. После изменений [слой сессии](../../app/session.tsx) обновляет полномочия и кэш.

Внешние коды точек используются [источниками](../data/README.md) для ограничения строк. Назначенные участники появляются в [разборах](../cases/README.md) только при достаточном доступе к их области. Сервер повторяет все проверки независимо от состояния кнопок.

Маршрут находится в [pages](pages/README.md), формы управления — в [components](components/README.md), описания ролей — в [model](model/README.md).
