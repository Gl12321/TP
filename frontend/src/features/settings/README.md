# Команда и область ответственности

Роль определяет доступные действия, а набор точек — доступные данные. Настройки позволяют пригласить сотрудника с нужными полномочиями, изменить его область и отключить доступ, сохранив историю работы.

[SettingsPage.tsx](SettingsPage.tsx) содержит профиль, команду и справочник точек. Владелец пространства защищён от обычного ограничения доступа. [InvitationsPanel.tsx](InvitationsPanel.tsx) выдаёт одноразовую ссылку; сотрудник задаёт пароль при принятии либо входит существующим аккаунтом. Ссылка показывается только при создании, хранить её в клиентском хранилище не требуется.

[SecurityPanel.tsx](SecurityPanel.tsx) меняет пароль и завершает остальные сеансы. [CreateWorkspace.tsx](CreateWorkspace.tsx) создаёт отдельную сеть с независимыми данными и участниками. После изменений [слой сессии](../../app/session.tsx) обновляет полномочия и кэш.

Внешние коды точек используются [источниками](../data/README.md) для ограничения строк. Назначенные участники появляются в [разборах](../cases/README.md) только при достаточном доступе к их области. Сервер повторяет все проверки независимо от состояния кнопок.
