# Описания ролей

[roles.ts](roles.ts) поясняет, какие задачи выполняют руководитель, региональный менеджер, франчайзи, управляющий точки, аналитик и администратор. Описания помогают выбрать роль при назначении доступа.

Используйте `roleDescriptions` в [настройках](../pages/SettingsPage.tsx) и формах управления участниками. Это текст интерфейса: доступные действия и область данных приходят из серверной сессии.
