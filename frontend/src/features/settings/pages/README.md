# Настройки пространства

[SettingsPage](SettingsPage.tsx) объединяет собственный профиль, управление командой и справочник точек. Вкладка хранится в `tab` адреса; при отсутствии права управления участниками доступен собственный профиль.

Страница подключается маршрутом настроек в [App](../../../app/App.tsx). Формы и панели находятся в [components](../components/README.md), а пояснения ролей — в [model](../model/README.md).
