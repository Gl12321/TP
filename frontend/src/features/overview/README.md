# Общая картина сети

Обзор отвечает на три вопроса: сколько получено по выбранному показателю, какой план согласован и что изменилось относительно предыдущего периода. Отсутствующие значения показаны отдельно от нуля. Сравнение использует только одинаковые точки с данными в обоих периодах.

[Страница обзора](pages/OverviewPage.tsx) получает готовый расчёт backend через [useOverview](hooks/useOverview.ts). [Фильтры области](components/ScopeFilters.tsx) изменяют период, точку и показатель в URL. [Сравнение периодов](components/PeriodComparison.tsx) показывает серверное сравнение; полосы лишь иллюстрируют переданные значения и не являются отдельным расчётом.

Из обзора открывается [карточка точки](../stores/README.md) или [ассистент](../assistant/README.md) с выбранной областью. Настройка показателя и плана находится в [данных](../data/README.md). Обзор не вызывает модель.

До появления первого показателя отображаются [первые шаги](../onboarding/README.md): справочник точек, доступный источник с разрешёнными таблицами и определение расчёта. Их готовность вычисляется из настоящих данных пространства. Ошибка загрузки справочника показывается как ошибка, а не как незавершённая настройка.

Общие карточки и фильтры находятся в [components](components/README.md), запрос расчёта — в [hooks](hooks/README.md). Их использует также страница точки с фиксированным идентификатором магазина.
