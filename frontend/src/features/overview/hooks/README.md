# Запрос обзора

[useOverview](useOverview.ts) получает серверный расчёт для периода, показателя и выбранных точек. Параметры берутся из URL; если показатель не выбран явно, используется первый доступный. Без показателя запрос расчёта не запускается.

[Обзор сети](../pages/OverviewPage.tsx) вызывает хук без аргумента, а [страница точки](../../stores/pages/StoresPage.tsx) передаёт `fixedStore`. Ключ кэша включает пространство и параметры, поэтому результаты разных областей не смешиваются.
