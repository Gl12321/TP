# Обзор сети

[OverviewPage](OverviewPage.tsx) собирает факт, план и сравнение периодов по выбранной области. Отсутствие данных показано отдельно от нулевого результата; пользователь может перейти к точке или продолжить исследование в ассистенте.

Страница подключается в [App](../../../app/App.tsx), получает расчёт через [useOverview](../hooks/useOverview.ts) и использует общие [компоненты обзора](../components/README.md). Расчёт выполняет backend по сохранённому определению показателя.
