# Точка как область работы

Карточка точки собирает её показатели, план, контекст владельца и связанные разборы. Управляющему не приходится искать свою точку в общей сети, а руководитель может перейти к ней из сравнения показателей.

[Страницы точек](pages/StoresPage.tsx) содержат поиск по справочнику и страницу отдельной точки. Факт и план приходят из серверного обзора с фиксированным идентификатором точки. При создании точки внешний код связывает её с полем фактов в источнике.

Справочник точек фильтруется по уже полученным данным. Связанные разборы карточки загружаются отдельно: сервер применяет `store_id` и возвращает страницы до 50 записей. Счётчик показывает загруженное количество, а «Показать ещё» продолжает выдачу по курсору. Пустая страница с курсором позволяет проверить более ранние доступные разборы. Ошибка обновления или дозагрузки сохраняет текущие карточки и позволяет повторить запрос.

[Компонент динамики](components/StoreDynamics.tsx) показывает динамику по дням или неделям в виде графика и таблицы. Сервер использует то же определение показателя; отсутствие строк остаётся пропуском. Сравнение с предыдущим периодом относится к этой точке.

Вопрос открывается в [ассистенте](../assistant/README.md) с областью этой точки. При создании [разбора](../cases/README.md) по настроенному показателю сервер фиксирует факт, план, определение, период и ограничения расчёта. Изменение справочника доступно администратору через [настройки](../settings/README.md); отображение страницы само по себе ничего не генерирует.
