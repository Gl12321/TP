# Динамика выбранной точки

[StoreDynamics](StoreDynamics.tsx) показывает изменение показателя по дням или неделям. Пользователь выбирает график или таблицу и может раскрыть основание расчёта.

Компонент получает идентификаторы точки и показателя вместе с границами периода от [страницы точки](../pages/StoresPage.tsx). Данные приходят из серверной аналитики; таблица и график используют общие компоненты [shared](../../../shared/README.md).
