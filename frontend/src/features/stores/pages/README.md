# Работа с точками

[StoresPage](StoresPage.tsx) содержит справочник точек и страницу выбранной точки. Справочник помогает найти точку по названию, коду, партнёру или городу; карточка показывает показатели, план и связанные разборы.

Обе страницы подключаются отдельными маршрутами в [App](../../../app/App.tsx). Динамика вынесена в [компонент](../components/StoreDynamics.tsx), а создание разбора использует [общую форму раздела разборов](../../cases/components/CaseCreateDialog.tsx), чтобы сохранить единое основание обсуждения.

Поиск справочника работает по полученному списку точек. Для связанных разборов `StorePage` использует `useInfiniteQuery` с серверным фильтром `store_id`, [getPage](../../../shared/api/client.ts) и [Pagination](../../../shared/ui/Pagination.tsx). Число внизу относится к загруженным разборам; окончание выдачи определяется отсутствием курсора, даже если последняя страница пуста. Ошибки обновления и дозагрузки показываются отдельно от сохранённых карточек.
