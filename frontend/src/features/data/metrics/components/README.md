# Форма определения показателя

[MetricDialog](MetricDialog.tsx) собирает источник, разрешённую таблицу, операцию и поля значения, даты и кода точки. Выбор источника определяет доступный каталог, поэтому форма не предлагает произвольные имена таблиц.

Диалог открывается из [списка показателей](../pages/MetricsPanel.tsx) для нового или существующего определения. Подписи операций берутся из [aggregation.ts](../model/aggregation.ts). Текст описания поясняет смысл расчёта и не исполняется как формула.
