# Список показателей

[MetricsPanel](MetricsPanel.tsx) показывает смысл, операцию и версию каждого определения. Пользователь может просматривать показатель или открыть создание и изменение при наличии соответствующего права.

Страница используется вкладкой показателей в [DataPage](../../pages/DataPage.tsx). Для редактирования она открывает [MetricDialog](../components/MetricDialog.tsx); после сохранения связанные запросы обновляются.
