# Определения показателей

Показатель связывает название и описание с источником, таблицей, операцией, датой и кодом точки. Это даёт обзору и карточкам точек одинаковое основание расчёта; изменение определения создаёт новую редакцию.

[Страница показателей](pages/MetricsPanel.tsx) показывает текущие определения, [форма](components/MetricDialog.tsx) выбирает разрешённые поля каталога, а [model](model/README.md) задаёт подписи операций. Раздел открывается вкладкой «Определения показателей» в [данных](../pages/DataPage.tsx); изменение доступно с правом `metrics:write`.
