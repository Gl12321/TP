# Названия операций

[aggregation.ts](aggregation.ts) связывает серверные значения `sum`, `count` и `avg` с понятными подписями: сумма, количество строк и среднее значение.

Используйте `aggregationLabels` в [списке](../pages/MetricsPanel.tsx) и [форме показателя](../components/MetricDialog.tsx), чтобы одно значение отображалось одинаково. Расчёт выполняется на сервере по сохранённому определению.
