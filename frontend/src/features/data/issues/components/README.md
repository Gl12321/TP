# Обсуждение проблемы с данными

[CreateIssue](CreateIssue.tsx) выбирает источник, описывает наблюдение и назначает получателя. [SourceIssueView](SourceIssueView.tsx) показывает сохранённое состояние источника и переписку; [IssueResolution](IssueResolution.tsx) меняет ответственного и состояние, сохраняя решение.

Формы используют отдельные черновики создания, комментария и решения. Закрытие обращения требует итога; повторное открытие сохраняет прежний вывод в истории. Ответ отправляется кнопкой либо Ctrl+Enter / ⌘+Enter.

Компоненты открываются из [списка обращений](../pages/SourceIssuesPanel.tsx) и получают контекст выбранной записи. Доступных ответственных возвращает [useSourceAdministrators](../hooks/useSourceAdministrators.ts); недоступный источник или участник блокирует соответствующую отправку.
