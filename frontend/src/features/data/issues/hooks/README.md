# Ответственные за источники

[useSourceAdministrators](useSourceAdministrators.ts) получает участников, которым можно адресовать техническое обращение в данном пространстве. Запрос использует отдельный серверный список, чтобы форме не требовался доступ ко всей команде.

Передавайте идентификатор пространства из контекста. Хук возвращает состояние запроса для [создания обращения](../components/CreateIssue.tsx) и [смены ответственного](../components/IssueResolution.tsx); ключ кэша включает пространство.
