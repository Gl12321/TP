# Список обращений

[SourceIssuesPanel](SourceIssuesPanel.tsx) помогает найти проблему по теме, источнику и состоянию. Параметры списка и открытая карточка находятся в URL, поэтому переход назад восстанавливает выбор.

Компонент используется вкладкой обращений в [DataPage](../../pages/DataPage.tsx). Создание выполняет [CreateIssue](../components/CreateIssue.tsx), а выбранное обращение открывает [SourceIssueView](../components/SourceIssueView.tsx).

Значения `issue_q` и `issue_status` из URL передаются API как `q` и `filter`. `useInfiniteQuery` получает страницы через [getPage](../../../../shared/api/client.ts), а [Pagination](../../../../shared/ui/Pagination.tsx) показывает загруженное количество и продолжает выдачу по курсору. Страница также обновляется каждые 30 секунд. Ошибки обновления и следующей страницы сохраняют имеющиеся строки; пустая страница с курсором оставляет доступной кнопку продолжения.
