# Технические обращения

Обращение передаёт проблему с данными ответственному за источник: что проверяли, что наблюдали и каким было состояние подключения. Переписка помогает зафиксировать проверку и решение без передачи финансовых результатов техническому администратору.

[Страница обращений](pages/SourceIssuesPanel.tsx) сохраняет поиск и фильтр в URL. [Компоненты](components/README.md) создают обращение, показывают переписку и фиксируют решение; [хук участников](hooks/README.md) получает доступных администраторов, а [model](model/README.md) задаёт подписи состояний.

Раздел открывается вкладкой «Обращения по данным» или уведомлением с параметром `issue`. Черновики живут в памяти сеанса; неизменённая форма создания повторяется с тем же ключом операции после ошибки связи.

Сервер применяет поиск и фильтры «Активные», «Мои», «Решённые» и «Все» ко всей доступной истории. Список загружается страницами до 50 записей; счётчик отражает только полученные обращения. «Показать ещё» доступна и после пустой страницы с курсором, поскольку далее могут находиться более ранние записи, прошедшие проверку доступа. Ошибка обновления или дозагрузки не скрывает текущие строки и даёт повторить запрос.
