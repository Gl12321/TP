# Планы по точкам

План задаёт согласованное значение показателя для точки и месяца. Сохранение создаёт редакцию и связывает значение с версией определения показателя.

[PlansPanel](pages/PlansPanel.tsx) содержит список за выбранный месяц и форму задания плана. Просмотр доступен на вкладке «Планы точек» в [данных](../pages/DataPage.tsx), а изменение требует `plans:write`. [Обзор](../../overview/README.md) использует сохранённые планы для сопоставления с фактом.
