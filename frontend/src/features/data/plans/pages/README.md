# Просмотр и изменение планов

[PlansPanel](PlansPanel.tsx) загружает планы, точки и определения показателей, затем показывает значения за выбранный месяц. Форма создания и изменения остаётся рядом со списком, поскольку относится только к этому экрану.

Компонент подключается из [DataPage](../../pages/DataPage.tsx). Для нового плана нужны доступные точка и показатель; изменение существующего значения сохраняет его область. После сохранения обновляются запросы пространства, включая расчёты, использующие план.
