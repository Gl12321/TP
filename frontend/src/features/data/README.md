# Откуда берутся числа

Чтобы разные сотрудники видели сопоставимые показатели, команда должна согласовать источник, доступные поля, смысл расчёта и план. Этот раздел собирает эти решения в одном месте, сохраняя разные полномочия администратора, аналитика и руководителя.

[Подключения](sources/README.md) создают и изменяют подключения PostgreSQL, запускают проверку и настраивают таблицы. По умолчанию поля закрыты. Факты требуют разрешённого поля внешнего кода точки; общий справочник открывается только явным выбором. Пустой пароль при редактировании сохраняет имеющийся секрет. Сохранение неизменённых полей не пересоздаёт подключение.

У источника есть аудитория чтения: все участники с правом аналитики либо явный список. Пустой список закрывает чтение всем. Это позволяет создать отдельные профили продаж и расходов с разными таблицами, учётными записями PostgreSQL и получателями. Техническое право администратора менять подключение не предоставляет ему финансовый доступ.

[Определения показателей](metrics/README.md) связывают понятное описание с разрешённой таблицей, операцией, датой и ключом точки. Описание не исполняется как формула: особенности возвратов и других корректировок должны быть отражены в подготовленных данных. Изменение создаёт новую редакцию определения. [Планы](plans/README.md) сохраняют план для точки, месяца и конкретной версии показателя.

[Обращения по данным](issues/README.md) передают техническую проблему администратору: источник, наблюдение и состояние последней проверки сохраняются при создании обращения. В [карточке обращения](issues/components/SourceIssueView.tsx) команда обсуждает проблему, назначает ответственного и фиксирует исправление. Решение обязательно для закрытия; повторное открытие сохраняет старый вывод в переписке. Уведомление ведёт прямо в нужную карточку. Администратор без финансовых полномочий работает с подключениями и этой перепиской, не получая результаты запросов, отчёты и показатели.

Поиск по теме или источнику и фильтр обращений сохраняются в адресе страницы; возвращение из карточки и кнопка браузера «Назад» восстанавливают выбор. Формы обращения, ответа и решения сохраняют черновик при переходах внутри пространства. Черновики живут в памяти, сбрасываются при перезагрузке страницы, выходе, смене пространства или аккаунта и не записываются в браузерное хранилище. Ответ отправляется кнопкой либо Ctrl+Enter / ⌘+Enter. При отправке поля блокируются, а после сохранения появляется подтверждение.

[Обзор](../overview/README.md) использует эти определения без модели. [Ассистент](../assistant/README.md) получает выбранный показатель как часть контекста. Привязка кодов и назначение области сотрудникам находятся в [настройках](../settings/README.md).

[Страница раздела](pages/DataPage.tsx) выбирает вкладку по `tab` в URL и полномочиям пользователя. Код каждого направления находится в своей папке: страницы собирают сценарий, компоненты содержат формы и карточки, хуки выполняют общие запросы, а модели задают подписи и проверку значений.
