# Откуда берутся числа

Чтобы разные сотрудники видели сопоставимые показатели, команда должна согласовать источник, доступные поля, смысл расчёта и план. Этот раздел собирает эти решения в одном месте, сохраняя разные полномочия администратора, аналитика и руководителя.

[SourcesPanel.tsx](SourcesPanel.tsx) создаёт и изменяет подключения PostgreSQL, запускает проверку и настраивает таблицы. По умолчанию поля закрыты. Факты требуют разрешённого поля внешнего кода точки; общий справочник открывается только явным выбором. Пустой пароль при редактировании сохраняет имеющийся секрет. Сохранение неизменённых полей не пересоздаёт подключение.

У источника есть аудитория чтения: все участники с правом аналитики либо явный список. Пустой список закрывает чтение всем. Это позволяет создать отдельные профили продаж и расходов с разными таблицами, учётными записями PostgreSQL и получателями. Техническое право администратора менять подключение не предоставляет ему финансовый доступ.

[MetricsPanel.tsx](MetricsPanel.tsx) связывает понятное описание с разрешённой таблицей, операцией, датой и ключом точки. Описание не исполняется как формула: особенности возвратов и других корректировок должны быть отражены в подготовленных данных. Изменение создаёт новую редакцию определения. [PlansPanel.tsx](PlansPanel.tsx) сохраняет план для точки, месяца и конкретной версии показателя.

[Обзор](../overview/README.md) использует эти определения без модели. [Ассистент](../assistant/README.md) получает выбранный показатель как часть контекста. Привязка кодов и назначение области сотрудникам находятся в [настройках](../settings/README.md).
