# Подключения и разрешённые таблицы

Источник связывает пространство с PostgreSQL и определяет, какие таблицы и поля разрешено читать. Аудитория источника задаётся отдельно от технического права менять подключение.

[Страница подключений](pages/SourcesPanel.tsx) собирает список и действия администратора. [Компоненты](components/README.md) проверяют соединение, открывают каталог и редактируют правила чтения; [модель правил](model/README.md) подготавливает форму и проверяет её значения. Раздел открывается вкладкой «Источники и доступ» на [странице данных](../pages/DataPage.tsx).
