# Список подключений

[SourcesPanel](SourcesPanel.tsx) помогает администратору увидеть состояние источников и открыть нужную настройку. Страница загружает подключения пространства и показывает карточки либо состояние загрузки, ошибки или пустого списка.

Компонент используется вкладкой источников в [DataPage](../../pages/DataPage.tsx). Проверка подключения и редактирование вынесены в [карточку источника](../components/SourceCard.tsx) и связанные диалоги.
