# Настройка источника

[SourceCard](SourceCard.tsx) показывает состояние подключения и действия над ним. [SourceCreateDialog](SourceCreateDialog.tsx) создаёт или меняет реквизиты и аудиторию; пустой пароль при редактировании сохраняет текущий секрет.

[CatalogDialog](CatalogDialog.tsx) показывает полученные от сервера таблицы, а [PolicyEditor](PolicyEditor.tsx) выбирает разрешённые поля и способ ограничения строк. Для фактов требуется поле кода точки; общий справочник разрешается явно. Правила формы находятся в [model](../model/README.md).

Диалоги открываются из [списка источников](../pages/SourcesPanel.tsx), получают выбранный источник и закрываются после успешного сохранения. Актуальные разрешения и доступность подключения проверяет API.
