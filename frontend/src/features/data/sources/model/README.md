# Правила чтения таблиц

[policies.ts](policies.ts) преобразует каталог в редактируемый `PolicyDraft` и проверяет выбранные разрешения. Включённая таблица должна содержать разрешённые поля; для таблицы фактов поле кода точки должно входить в этот список.

[PolicyEditor](../components/PolicyEditor.tsx) вызывает `policyDraft` при открытии каталога и `validatePolicies` перед сохранением. Эти функции проверяют форму; сервер независимо проверяет и применяет правила доступа.
