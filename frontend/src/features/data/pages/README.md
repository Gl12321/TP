# Раздел данных

[DataPage](DataPage.tsx) объединяет подключения, обращения, определения показателей и планы. Доступные вкладки зависят от полномочий, а выбранная вкладка хранится в параметре `tab` адреса.

Страница подключается маршрутом `/w/:workspaceId/data` в [App](../../../app/App.tsx). Содержимое вкладок находится в отдельных направлениях [data](../README.md); формы и запросы остаются рядом со своим направлением.
