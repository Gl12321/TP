# Проверки интерфейса

Проверки защищают важные свойства продукта: точность финансовых значений, отсутствие формул в экспортируемых текстовых ячейках, скрытие отозванных результатов, восстановление сеанса и работу пользователя с настоящим API.

`npm test` запускает Vitest и Testing Library. Тесты проверяют десятичные значения за пределами точности JavaScript Number, отрицательные и маленькие суммы, CSV, CSRF, ошибки доступа, выбор разрешённых полей, пагинацию и смену состояния входа. Фикстуры результата существуют только в тестах и не подключаются к приложению.

[browser/workspace.spec.ts](browser/workspace.spec.ts) проверяет реальный путь: вход, новая точка, разбор, комментарий, приглашение, регистрация управляющего, адресный вопрос, ответ, итог и мобильная навигация. Он изменяет данные, поэтому запускается только на изолированном тестовом экземпляре.

Для Playwright задайте `APP_UI_CREDENTIALS` — путь к локальному JSON с `url`, `email`, `password` тестового руководителя. Файл не должен попадать в репозиторий. `PLAYWRIGHT_CHANNEL=msedge` позволяет использовать установленный Edge; без этой переменной нужен браузер Chromium, установленный для Playwright. Команда запуска: `npm run test:browser`. Без пути к тестовому аккаунту тест пропускается. Скриншоты сохраняются в игнорируемый `test-results`.

[browser/analytics.spec.ts](browser/analytics.spec.ts) проверяет настоящий PostgreSQL: подключает отдельный источник, разрешает таблицы и поля через интерфейс, определяет показатель, задаёт планы двух точек и сверяет обзор с контрольными суммами. Дополнительно нужен `APP_UI_SOURCE` — путь к приватному JSON с тестовым подключением, справочником точек, политиками, определением показателя, планами и ожидаемыми числами. Тест создаёт отдельное рабочее пространство; источник должен содержать заранее подготовленные контрольные строки. Без файла он пропускается. Данные подключения не выводятся в отчёт теста.

Эти браузерные сценарии не загружают модель и не подтверждают качество генерации SQL. Для этого нужен отдельный запуск worker с настоящими весами. Браузер не подменяет успешными ответами отсутствующий источник.
