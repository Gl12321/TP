# Проверки SQL-агента

Эти проверки удерживают основные гарантии библиотеки: агент использует только разрешённые таблицы и колонки, исправляет SQL в заданных пределах и не выполняет запрос после отказа, отмены или изменения доступа. Набор компактный: несколько содержательных сценариев проверяют весь путь, а варианты SQL сведены в таблицы примеров.

Демонстрационный режим приложения существует отдельно от проверок. Тесты создают свои краткоживущие данные; для них не нужны демонстрационные аккаунты, работающий API или скачанные модели.

## Устройство набора

| Файл | Что проверяется |
| --- | --- |
| [test_pipeline.py](sql_agent_tests/test_pipeline.py) | Получение настоящего результата SQL, исправления и их предел, однократное расширение контекста, отказы, отмена, дедлайн, изменение доступа, ошибки исполнения и изоляция недоверенного текста в промпте |
| [test_sql_grammar.py](sql_agent_tests/test_sql_grammar.py) | Базовая аналитика, опасные и некорректные конструкции, экранирование имён и отдельный протокол отказа |
| [test_sql_validation.py](sql_agent_tests/test_sql_validation.py) | Проверка AST, запрет записи и неподдерживаемых конструкций, доступ только к разрешённым таблицам и колонкам |
| [test_retrieval.py](sql_agent_tests/test_retrieval.py) | Разделение кеша по читателю, каталогу и модели, восстановление повреждённого кеша, широкие таблицы, связующие таблицы и предел контекста |
| [gbnf_support.py](sql_agent_tests/gbnf_support.py) | Небольшой распознаватель для проверки строк по реально собранной GBNF |

В pipeline генератор выдаёт заранее заданные ответы, после чего работают настоящие подбор контекста, грамматика, AST и цикл исправления. Для проверки чисел используется временная SQLite с переносимыми SQL-выражениями. Это не подмена PostgreSQL в приложении: его особенности и ограничение строк по правам проверяются в [наборе backend](../../../backend/tests/README.md).

## Запуск

Из корня репозитория, после установки зависимостей разработки:

```text
python tools/check.py agent
```

Прямой запуск того же набора:

```text
python -m pytest packages/sql_agent/tests -q
```

Для одной области укажите конкретный файл, например:

```text
python -m pytest packages/sql_agent/tests/sql_agent_tests/test_sql_grammar.py -q
```

Набор не скачивает веса, не запускает llama.cpp и не требует PyTorch или сервера PostgreSQL. Общие команды и необходимые зависимости перечислены в [руководстве по проверкам](../../../docs/development/testing.md).

## Границы и расширение

Распознаватель GBNF проверяет допустимость строк, но не совместимость с конкретной сборкой llama.cpp. Заданные ответы генератора проверяют управление запросом, но не качество модели. После смены модели или её шаблона отдельно оцениваются реальные вопросы с известными результатами, расход памяти и отмена генерации.

При изменении грамматики добавляйте один поддерживаемый пример и соответствующий запрещённый вариант в существующие наборы. При изменении управления запросом расширяйте сценарий pipeline с наблюдаемым результатом: выполненный SQL, число попыток, возвращённая таблица или запрет исполнения. Не дублируйте проверки адаптеров приложения внутри библиотеки. Общий путь изменения ядра описан в [руководстве разработчика](../../../docs/development/sql-agent.md).
