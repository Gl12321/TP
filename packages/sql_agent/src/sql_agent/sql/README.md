# Проверка и выполнение аналитического SQL

Модель может ошибиться даже при правильной форме запроса. Этот модуль проверяет, что получен ровно один разрешённый SELECT, все источники и поля существуют в переданном каталоге, а выражения соответствуют поддерживаемому аналитическому языку.

[validation.py](validation.py) разбирает AST через sqlglot, проверяет область видимости JOIN, группировки, агрегаты, функции и лимиты. `SELECT *` и `tN.*` раскрываются в явный список разрешённых колонок, поэтому последующее добавление скрытого поля в исходной таблице не расширяет выдачу.

[grammar](grammar/README.md) ограничивает генерацию до проверки AST. [results.py](results.py) переводит значения PostgreSQL в JSON без потери точности Decimal: денежные значения передаются строкой, даты — в ISO, двоичные данные — в явном Base64-представлении.

Соединение с PostgreSQL предоставляет приложение через `ReadOnlyExecutor`. Этот модуль не хранит пароль, не создаёт роль и не внедряет пользовательский фильтр доступа. Ограничение строк по клиенту и точкам, роль чтения, таймаут и предел выдачи обязательны на стороне исполнителя. [Pipeline](../pipeline/README.md) передаёт нормализованные ошибки обратно в исправление.
