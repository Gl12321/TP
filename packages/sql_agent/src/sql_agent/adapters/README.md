# Локальные модели

Адаптеры подключают реальные модели к независимому SQL-ядру. Основная модель формирует запрос; encoder и reranker находят подходящие таблицы. Эти компоненты загружает один фоновый процесс, чтобы обычные HTTP-запросы не создавали дополнительные копии весов.

[llama.py](llama.py) работает с локальным GGUF через llama-cpp-python. Путь и параметры передаются явно. До загрузки проверяются размер весов, дополнительный резерв рабочего состояния и свободная RAM для приложения; во время генерации доступная память проверяется периодически. Общий дедлайн вопроса ограничивает локальный дедлайн генерации. Отмена дожидается выхода нативного вызова перед повторным использованием модели.

Эти проверки уменьшают риск исчерпания памяти, но не предсказывают все нативные выделения. Значение `runtime_memory_mb` — настраиваемый резерв, а не измерение KV-кэша. На Windows проверяется доступная память ОС; в Linux также учитываются ограничения cgroup. Профиль 27B принимается только после совместного прогона с БД и вспомогательными моделями.

[embedding.py](embedding.py) поддерживает явные `query_prefix` и `passage_prefix`, размерность и нормализацию. Для E5 используются `query: ` и `passage: `. Эти параметры вместе с revision модели входят в fingerprint индекса. Все файлы загружаются только из локального кэша, без `trust_remote_code`.

Encoder и reranker выполняются напрямую через Transformers и CPU PyTorch. E5 усредняет представления только настоящих токенов по attention mask и нормализует вектор; padding не меняет смысл документа. Такое выполнение соответствует [описанию E5](https://huggingface.co/intfloat/multilingual-e5-small) и не требует отдельного стека Sentence Transformers, SciPy или scikit-learn.

[reranker.py](reranker.py) ожидает один скалярный logit на пару текстов. Для каждой таблицы оцениваются фрагменты колонок; используется наибольшая оценка. Преобразование sigmoid сохраняет порядок, но не делает оценку вероятностью корректного ответа. По умолчанию кандидаты не отбрасываются по старому порогу другой модели.

Общий загрузчик приложения скачивает и проверяет закреплённые файлы моделей. Пакет не выбирает модель по объёму RAM и не скачивает замену при ошибке. Граница поиска описана в [retrieval](../retrieval/README.md), общий протокол — в [README пакета](../../../README.md).
