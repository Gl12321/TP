# Поиск нужных данных

Пользователь называет показатель, город или товар, а модель должна получить конкретные поля и связи. Этот модуль превращает разрешённый каталог в небольшой набор таблиц для ответа. Хороший подбор контекста снижает вероятность выдуманного поля и оставляет модели место для самого запроса.

## Как устроен поиск

[serializer.py](serializer.py) описывает таблицы, колонки и связи. Широкие таблицы делятся на группы колонок, поэтому поле в конце большой схемы не исчезает из-за ограничения длины encoder.

[semantic.py](semantic.py) сравнивает вектор вопроса с векторами этих фрагментов. Оценкой таблицы становится максимальное сходство её фрагментов. Затем переданный reranker повторно оценивает найденных кандидатов. Для такого ограниченного каталога используется точное сравнение векторов; отдельная векторная БД не требуется.

[context.py](context.py) добавляет кратчайшие пути по внешним ключам. Таблица с необходимыми связующими таблицами включается одной группой. Проверка размера использует фактический токенизатор генератора. Основание продолжения и выбранный показатель задают обязательные таблицы; нехватка места для них возвращается явной ошибкой.

## Кеш и границы данных

Ключ индекса включает namespace организации/источника/области, версию каталога, содержимое схемы и fingerprint embedder. Изменение этих данных создаёт другой индекс. Возвращённые поиском объекты сверяются с текущим разрешённым каталогом.

На диске сохраняются векторы и проверяемый ключ в JSON. Запись атомарная; повреждённый кеш пересоздаётся. Кеш в памяти ограничен числом каталогов, объём одного индекса — числом фрагментов. Дисковый кеш является восстановимыми производными данными: его можно удалить при остановленном worker.

Кеш содержит информацию, полученную из схемы клиента. Он не должен находиться среди публично раздаваемых файлов. Ни наличие вектора, ни высокая оценка таблицы не дают пользователю разрешения на данные.

## Связи и изменение

Модели предоставляет [adapters](../adapters/README.md), разрешённый снимок — приложение через `AllowedCatalog`, последовательность вызовов — [pipeline](../pipeline/README.md). При смене encoder, префиксов, нормализации или сериализации нужно изменить идентичность индекса и проверить разделение каталогов.

Поиск помогает найти таблицу. Смысл выручки, статус оплаченного заказа и допустимую область строк определяют метаданные и бизнес-приложение.
