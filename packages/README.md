# Самостоятельные компоненты

Здесь находится код, который можно использовать вне веб-приложения. Такое разделение позволяет развивать SQL-ядро и проверять его контракт независимо от аккаунтов, интерфейса и способа размещения SaaS.

[sql_agent](sql_agent/README.md) устанавливается как обычный Python-пакет. Он получает разрешённый каталог, генератор и исполнитель чтения через явные интерфейсы. Роли, источники и сохранение результатов остаются ответственностью [backend](../backend/README.md). Импорт пакета не загружает нейросети; локальные адаптеры устанавливаются отдельной группой зависимостей.

Грамматика включена в wheel, поэтому пакет не требует путей к исходному репозиторию. Сборка из корня: `python -m build packages/sql_agent --wheel`. Проверки поведения находятся внутри пакета в [tests](sql_agent/tests/README.md).
