# Библиотеки проекта

Здесь находятся компоненты, которые можно подключить к другому приложению без аккаунтов, HTTP и интерфейса «Разбора». Отдельный пакет нужен, чтобы бизнес-приложение и алгоритм ответа на вопрос развивались независимо и имели явный контракт.

Сейчас такой компонент один — [SQL-агент](sql_agent/README.md). Он превращает вопрос на обычном языке в запрос к PostgreSQL и возвращает таблицу вместе с SQL. Приложение предоставляет разрешённую структуру данных и исполнитель чтения; библиотека подбирает контекст, вызывает модель и проверяет запрос.

## Как организован пакет

Исходники находятся в `sql_agent/src/sql_agent`, переносимые проверки — в `sql_agent/tests`, зависимости и ресурсы wheel описаны в [pyproject.toml](sql_agent/pyproject.toml). Базовая установка содержит только SQL-ядро. Локальные модели подключаются дополнительной группой `local`.

Бэкенд импортирует установленный пакет, а не копирует его файлы. При этом пользователи, права на данные, подключения к PostgreSQL, очередь заданий и сохранение результатов остаются в [backend](../backend/README.md). Интерфейс обращается к API бэкенда и не знает о внутренних классах библиотеки.

## Разработка и поставка

Из корня репозитория пакет устанавливается командой `python -m pip install -e ./packages/sql_agent`. Для сборки wheel без установки в приложение: `python -m pip wheel --no-deps ./packages/sql_agent --wheel-dir dist`. В wheel включены файлы GBNF и аннотации типов `py.typed`.

Контракт, подключение, модели и правила изменения ядра описаны в [руководстве разработчика агента](../docs/development/sql-agent.md). Интеграция с остальным продуктом — в [общей архитектуре](../docs/ARCHITECTURE.md).
